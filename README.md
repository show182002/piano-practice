# 鋼琴練習 · Piano Practice

簡單網上鋼琴練習（第一版 `v0.00001`）。

## 功能
- 螢幕虛擬鋼琴（25 鍵，對齊 Arturia MiniLab 3 音域：C3–C5）
- Web Audio 出聲（無需外部音色檔）
- Web MIDI：接 USB MIDI keyboard 可同步亮鍵 + 出聲
- 八度偏移、音量
- 電腦鍵盤簡易試彈（A/W/S/E/D…）

## 用法
1. 開網頁後先撳「開聲」
2. 接上 MiniLab 3（或其他 MIDI keyboard），撳「連接 MIDI」，瀏覽器允許權限
3. 建議用 Chrome / Edge（Web MIDI 支援較完整）

## 之後可加
和弦提示、轉調、五度圈、更好嘅鋼琴音色（SoundFont）等。
