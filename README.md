# 鋼琴練習 · Piano Practice

簡單網上鋼琴練習（`v0.03400`）。

線上：https://show182002.github.io/piano-practice/

## 功能
- 主頁列出所有曲目。選《單車》之後有兩個模式：「跟譜練習」同新嘅「遊戲」（跌落音符）。《Shall We Talk》仍然只有跟譜練習，冇遊戲掣
- 練習介面跟教學 app／音遊：上面係大譜表（高音譜＝旋律 solo，低音譜＝和弦；垂直 playhead 跟住走），旋律音名同步喺五線譜下面對住每個音，MiniLab 3 虛擬鍵盤（25 鍵，預設 C3–C5）鎖喺譜下面。鍵盤每粒鍵用固定像素闊度，可用「鍵盤大小」按比例一齊縮放（約 70% 至填滿畫面闊度），唔會跟視窗拉肥
- 譜視窗預設睇 4 小節，播放緊可以調 2 至 6 節
- 播放區有橫向可拖動嘅 timeline，同單一圖示播放／暫停掣（約 44 像素；播緊顯示暫停，其餘顯示播放，唔會變灰）。旁邊有細粒「由頭」（播緊就由頭再播；暫停或停止就跳去開頭並保持原狀態）。練習頁可用空白鍵播放／暫停（再按就繼續；播完再按會由頭開始，唔會當成停止），左右方向鍵倒帶／快轉 5 秒（播緊、暫停或停止都可以，再撳播放會由新位置繼續；喺填詞盒等輸入欄打字時呢啲快捷鍵唔會生效）
- 跟播示範音用旋律／和弦嘅 M（靜音）同 S（只聽呢條）控制，標準 DAW 邏輯；兩邊都靜音（或 S／M 結果聽唔到）就唔出示範聲，只跟譜同鍵盤高亮。M／S 只影響示範音，唔影響你自己彈或者鍵盤顯示。選擇會記低（`piano-practice-mute-melody` 等），預設兩條都聽到。自己彈嘅鍵同 MIDI 仍然會出聲
- 兩條 track 可以分開決定鍵盤上見唔見到按鍵色。和弦高亮用該組 voicing 嘅實際 MIDI，唔會因為同一個音名而連上／下一組八度一齊亮。若該 Level 有明確嘅左手伴奏音（`accompaniment` / `leftHand`），低音譜、和弦示範音同鍵盤高亮會跟呢啲音，而唔再用符號產生嘅柱式和弦（和弦符號仍然會顯示）
- 螢幕虛擬鋼琴、Web MIDI（接 USB keyboard 可同步亮鍵 + 出聲）
- **Salamander Grand Piano** 取樣音色（全 88 鍵、A0–C8、1 層力度；未錄到嘅音由最接近樣本移調）。示範同現場彈奏／MIDI 都用呢套音色；載入失敗會退回電子波，唔會無聲。力度會跟住開聲大小，輕重係大聲細聲（1 層唔會改音色明暗）。取樣已做響度補償（約 11 倍 voice peak，比先前 7 倍更大聲），主路徑有安全限制器，避免大聲和弦爆音；音量掣仍然 0–100，預設 90
- 「殘響」可由乾調到濕（預設係中等、類似一般 piano demo 站嘅大廳感，明顯乾過樣本原裝 12 秒尾音），設定會記低
- **跟彈《單車》**（陳奕迅；練習用編曲，G 大調）。預設 **Level 3**：跟 C_Zhukov 簡易鋼琴譜第 1 頁（pickup＋第 1–30 小節）寫上單音旋律同小節中間嘅 slash chord。第 2 頁（第 31–56 小節）未有收入
- **《Shall We Talk》**（陳奕迅；練習用編曲，並非官方譜；C 大調，約 86 BPM）可喺主頁同《單車》一齊揀。Level 3 跟 LouisLiao Synthesia 簡易教學嘅右手旋律同左手分解／走位（結尾原片有 rit.，練習 app 維持 86 BPM）。Level 2 將左手收成有少少變化嘅和弦（經過音分析回和弦），Level 1 係每四拍一個主要和弦（兩個 2/4 小節各用一組）。官方歌詞不會預載，請用返「填詞」盒（`piano-practice-lyrics-` + 歌曲 id）。《單車》不變
- 冇歌詞嘅段落當 Intro／間奏，唔顯示和弦（《單車》第 1 頁：pickup＋第 1–4 小節，同第 22–24 小節；《Shall We Talk》：video m2–5 前奏，同 m34–35、m70–71 間奏）。歌詞開始之後先顯示旋律＋和弦
- Level 3 譜下面每個旋律音預設顯示音名（例如 A4、F#4）；前奏同間奏只顯示段落名稱，唔放音名。可用「填詞」盒貼上自己寫嘅整段詞，撳「套用」就一個字對一個音取代音名（空白同標點會跳過；字數唔夠就保留音名，多出嚟嘅字會忽略）。詞只存於瀏覽器 `localStorage`（`piano-practice-lyrics-` + 歌曲 id，例如 `piano-practice-lyrics-danche`），可用「還原音名」清除。**官方歌詞不會預載於公開網站**
- 「歌詞大小」可以縮放譜下面嘅音名同自貼歌詞（約 70%–200%，預設 100%，唔會改現有排版）。設定記低（`piano-practice-lyric-size`）。放大時譜會加高少少，避免字同低音譜重叠；playhead、而家嗰個字嘅黃色高亮、一字對一音對齊，同前奏／間奏段落名稱都會跟住。
- 「結他和弦」喺譜／歌詞同鍵盤之間顯示一排標準六弦結他和弦圖（跟譜視窗 2–6 小節、時間順序；同一個符號出現多次就畫多次）。可開關同放大縮小（約 70%–180%）；播緊、暫停、拖動、由頭或換歌時，會高亮 playhead 而家嗰個和弦（包括小節中間轉和弦）。前奏／間奏如果進行入面有和弦符號，仍然會出圖（譜上可能隱藏符號）；冇符號嘅位置唔會發明和弦。《單車》雖然冇伴奏音軌，都會跟 `progression` 出圖。關掉就成條帶收起。設定記低（`piano-practice-guitar-chords` 預設開，`piano-practice-guitar-chord-size`）。窄橫向可以橫向捲動，唔會壓扁譜。
- 拍子機、BPM（《單車》預設 68，《Shall We Talk》預設 86，範圍 40–120）。拍子機喺主列用圖標掣（開咗會亮；tooltip 係「拍子機」）；窄橫向如果主列放唔落先會收喺「更多」。預設開，關掉會記低（`piano-practice-metronome`），唔會每次入練習頁又自動開返
- 手機請打橫使用；直向會提示轉橫，橫向模式會簡化控制（Level、BPM、鍵盤大小、歌詞大小、結他和弦同大小、音量、殘響、八度、鍵盤顯示同 MIDI 收喺「更多」；旋律／和弦 M／S 仍然留喺主列）
- **《單車》遊戲模式**：選歌之後撳「遊戲」，用獨立全畫面嘅 Synthesia 風格鋼琴卷簾（唔會見到譜、結他和弦圖或填詞列）。彩色長條由上跌落到鍵盤頂一條清楚嘅紅色擊打線，條上面有音名字母（C、D、F♯…）；長音用長條由高處一路落到線；旋律綠、和弦藍。畫面左邊長期列出本曲 Level 3 全部 14 個唔同和弦（跟進行第一次出現嘅次序），每個符號旁邊有一個 25 鍵細鍵盤圖，亮起該和弦要按嘅鍵（用返遊戲 voicing）；方便暫停對住練。進行到邊個會標示；MIDI 或螢幕鍵撳中嗰個 voicing 會再高亮。列表喺寬螢幕左邊有預留位置，關咗和弦跌落軌仍然留住。鍵盤保持正常琴鍵比例、按比例縮放（唔會拉闊變肥），窄畫面會預留左邊列表位再縮鍵盤，C 鍵有細八度數字。撳螢幕琴鍵或 MIDI（兩者同一條路徑），對應嘅虛擬琴鍵會亮起，而嗰條音高嘅整條下跌色條都會明顯亮起（提早撳、對住正在接近擊打線嘅條都得）；打中之後一路亮到條過晒擊打線，或者當按鍵仍然按住。MIDI 音如果高過或低過畫面 25 鍵，會按八度摺入可視鍵盤，同撳嗰粒螢幕鍵一樣。對應琴鍵喺接觸位有白光。旋律同和弦可以分開開關（預設都開），示範聲亦可以分開開關（開咗就即使冇彈都聽得到；撳「聲」關咗就即時靜音該軌示範，自己彈仍然有鋼琴聲）。顯示同聲係兩組獨立掣。鍵盤仍然係預設 C3–C5，加現有八度偏移；超出視窗嘅音（例如副歌 D5–G5）會喺低／高一個八度嘅同一音名鍵出現，並標 `oct+`／`oct−`（顏色深少少），撳嗰粒鍵就算打中實際音高。和弦用返練習模式嘅 voicing。預設開「等到你撳先繼續」：音符跌到擊打線會停，等撳對先繼續；可以隨時關。計分同 Combo 只喺遊戲模式出現，用嚟鼓勵，冇 Game Over，錯過唔會停歌。BPM 預設 68，玩緊可以隨時改，即時影響跌落速度同示範聲；上次用嘅遊戲 BPM 會記低（`piano-practice-game-` 開頭嘅設定一併記喺瀏覽器）。遊戲只用 Level 3 第 1 頁（pickup＋第 1–30 小節），完咗就停，唔會發明第 2 頁。螢幕琴鍵同 MIDI 都可以計分
- **五度圈**係獨立頁：揀大調 → 顯示音階、常用和弦、相對小調；鍵盤亮起相關音符
- 八度偏移、音量、電腦鍵盤簡易試彈（A/W/S/E/D…）

- `audio/salamander/` — 30 個 OGG 樣本（CC BY 3.0, Alexander Holm）
- `js/midi.js` — Web MIDI 連接
- `js/piano.js` — 虛擬鍵盤 UI（固定鍵寬、可按比例縮放，唔會拉闊變肥；`PianoUI` 可 mount 到指定容器；MIDI 同螢幕鍵共用 press 路徑，超出 25 鍵視窗嘅音會按八度摺入再亮鍵；和弦用精確 MIDI 高亮，旋律金、和弦藍；C 鍵有八度數字）
- `js/theory.js` — 音階／和弦理論（`chordPcsFromSymbol`、slash chord、以及 MiniLab 音域內嘅簡單 voicing）
- `js/circleOfFifths.js` — 五度圈 UI 同選調邏輯
- `js/songs/danche.js` — 《單車》各 Level 和弦進行、Level 3 旋律，同歌詞時間軸（無預載官方歌詞）
- `js/songs/shallWeTalk.js` — 《Shall We Talk》各 Level 和弦進行、Level 3 旋律同左手伴奏，同歌詞時間軸（無預載官方歌詞）
- `js/guitarChords.js` — 結他和弦圖字典同 SVG 繪製（涵蓋兩首歌全部進行符號，包括 slash chord；#／♯ 等同寫法共用同一圖；未收錄嘅符號只顯示標籤佔位，唔會畫錯和弦）
- `js/followAlong.js` — BPM 時鐘、播放／暫停、「由頭」、可拖動進度條、空白鍵播放／暫停、方向鍵快轉 5 秒、橫向大譜表、譜下音名／自貼填詞同歌詞大小、結他和弦帶同 playhead 高亮、跟播示範同旋律／和弦 M／S；可用 `setSong` 切歌；Level 可帶明確左手伴奏音
- `js/gameMode.js` — 《單車》遊戲模式：跌落音符、左邊全部和弦列表（每個有細鍵盤 voicing 圖；進行中／撳中高亮）、清楚紅擊打線、按比例鍵盤、MIDI／螢幕鍵同一條高亮路徑、撳鍵整條色條明顯高亮、旋律／和弦顯示同示範聲開關、八度標記、等到你撳先繼續、鼓勵用計分、玩緊改 BPM
- `js/app.js` — 主頁列出 `Songs` 全部曲目、練習頁／遊戲頁／五度圈切換

## 用法
1. 開網頁後可喺主頁撳「開聲」（會載入鋼琴音色），或入練習頁直接撳播放／空白鍵，系統會自動開聲。如果瀏覽器擋住音訊，「開聲」會出現喺「更多」作後備。可用「殘響」調乾濕
2. 接上 MiniLab 3，喺主頁或練習頁「更多」撳「連接 MIDI」（建議 Chrome / Edge）；連到之後練習頁只顯示細狀態
3. 喺主頁揀一首歌。跟譜練習預設 Level 3。跟住譜上嗰條垂直 playhead、譜下音名、結他和弦圖同鍵盤高亮練習。可以拖動 timeline 跳去任一拍。顯示小節數可以喺播放緊調（2–6）。練習可以將 BPM 調慢。想先聽一次，用旋律／和弦嘅 M／S 決定聽邊條，再撳播放（亦可用空白鍵播放／暫停，左右方向鍵倒帶／快轉 5 秒）。作完詞可喺「填詞」盒貼上再撳「套用」。譜下字體同結他和弦圖可以喺「更多」用「歌詞大小」同「結他和弦」調
4. 《單車》可以改揀「遊戲」：音符由上跌落到鍵盤上面嘅線，對準就撳。左邊有全部和弦列表同每個和弦嘅細鍵盤圖，可以暫停對住練；MIDI 或螢幕鍵撳中嗰個會高亮，對應琴鍵同下跌色條亦會一齊亮。預設會等到你撳先繼續，亦可以喺玩緊改 BPM。旋律／和弦同各自嘅「聲」可以分開開關
5. **五度圈**：由主頁進入；撳一個大調，再撳「成個 scale」或某個和弦，睇鍵盤亮起

《單車》同《Shall We Talk》嘅和弦進行同旋律只供練習，並非官方譜。官方歌詞不會預載於公開網站。

## 之後可加
《單車》第 2 頁（第 31–56 小節）、有權使用嘅歌詞、更多力度層、結尾 ritardando 速度圖、其他歌曲嘅遊戲模式。
